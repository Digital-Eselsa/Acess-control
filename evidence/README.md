# Evidence

Store supporting text output or copies of generated lab artifacts here. Keep evidence organized by activity section.

- `log-analysis/` — optional copies of `sys_events.log` and `error_report.txt`.
- `permissions/` — optional `ls -l` output and access-test notes.
- `user-management/` — optional `id`, `getent`, and account-removal verification output.

Screenshots belong in the top-level `screenshots/` directory. Only include evidence generated by your own lab execution.
