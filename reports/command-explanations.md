## `grep`
`grep` searches text input or files for lines that match a specified pattern. In this activity, it is used to find `ERROR` entries and lines containing `root` or `user01`.

## `chown`
`chown` changes the user owner and, optionally, the group owner of a file or directory. In this activity, `sudo chown root:root confidential.txt` transfers ownership of the file to the root user and root group.

## `usermod`
`usermod` modifies an existing user account. The `-aG` options append the user to supplementary group membership; here they add `forensic01` or `guest1` to the `sudo` group without replacing other supplementary groups.
